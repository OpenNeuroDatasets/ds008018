Accession #: 
Description: This dataset set is composed of 58 TOF-MRA subjects.

Please cite the following reference if you use this dataset:

Cui Yue, et al. "A multicenter time-of-flight magnetic resonance angiography dataset and multifaceted cerebrovascular atlases of rhesus monkeys".

Here is an overview of the dataset organization: every original folder (i.e. non-derivative) contains the TOF-MRA of the subjects. Instead, the "derivatives" folder contains vascular atlases.
